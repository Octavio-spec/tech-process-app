# Экраны MVP

## 1. Список деталей

Поля:
- код детали
- наименование
- статус
- количество операций
- дата изменения

## 2. Карточка детали

Показывает:
- данные детали
- список операций
- визуальный маршрут

## 3. Карточка операции

Поля:
- номер операции
- название
- описание
- станок
- ячейка станка
- оснастка
- инструмент
- комментарий
- статус

Для станка, оснастки и инструмента:
можно выбрать из справочника или ввести вручную.

## 4. Магазин станка

Показывает:
- станок
- ячейки 1...N
- в каждой ячейке сборка / инструмент / резерв

## 5. Справочники

- станки
- инструменты
- оснастка
- сборки
