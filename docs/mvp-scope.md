# Состав MVP

В MVP входят:

1. Авторизация пользователя.
2. Список деталей.
3. Карточка детали.
4. Список операций по детали.
5. Карточка операции.
6. Справочник станков.
7. Справочник инструментов.
8. Справочник оснастки / оправок.
9. Экран магазина станка.
10. Ручные заглушки.
11. Отчёт "Список инструмента по детали".

Не входит в первый MVP:
- интеграция с 1С;
- складской учёт;
- закупки;
- стойкость инструмента;
- CAM-интеграция;
- сложные согласования.
