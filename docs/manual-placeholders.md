# Ручные заглушки

Ручная заглушка — это временный текст, если нужной записи ещё нет в справочнике.

Примеры:

Станок:
"любой вертикально-фрезерный с СОЖ"

Оснастка:
"подобрать длинную оправку HSK63A, вылет около 120 мм"

Инструмент:
"фреза Ø16, 4 зуба, черновая, аналога в базе нет"

У каждой заглушки должен быть статус:
- draft
- needs_catalog_entry
- converted_to_catalog
- rejected
