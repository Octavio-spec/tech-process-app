# Проект

Веб-приложение для технологов для замены Excel в части подбора оборудования, оснастки и инструмента.

Главная цепочка:
Деталь → Маршрут → Операция → Станок → Ячейка станка → Оснастка → Инструмент.

Цель MVP:
создать рабочую систему для 1–2 реальных деталей, где технолог может:
- создать деталь;
- создать маршрут;
- создать операции;
- выбрать станок, оснастку и инструмент;
- ввести ручную заглушку, если записи нет в справочнике;
- увидеть магазин станка по ячейкам;
- получить список инструмента и оснастки;
- экспортировать отчёт.

Стек:
- Next.js
- React
- TypeScript
- Supabase
- PostgreSQL
